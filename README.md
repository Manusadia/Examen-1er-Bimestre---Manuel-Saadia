# Landing Crop

Landing page minimalista de **Crop**. HTML + CSS estático, sin build.

- `index.html` — contenido
- `styles.css` — estilos (modo claro/oscuro automático)
- `vercel.json` — configuración de Vercel

## Deploy en Vercel

1. Entrá a https://vercel.com/new e importá este repositorio.
2. Framework preset: **Other**. No hace falta build command ni output directory.
3. Deploy. Cada push a `main` se publica automáticamente.
